Copilot Agents
==============

This folder contains custom agent definitions and prompt templates to improve developer workflows via prompt engineering. Enable or import these into your Copilot/agent runtime as needed.

Included agents:
- `prompt-engineer.agent.md` — helps craft and refine prompts
- `code-review.agent.md` — structured code review prompts
- `test-writer.agent.md` — generate unit and integration tests
- `refactor-assistant.agent.md` — plan and apply refactors safely
- `terminal-helper.agent.md` — shell/cli helper and safe command suggestions

To use: open an agent file, adapt the examples, and paste the `System`/`User` templates into your Copilot workspace or agent configuration.
