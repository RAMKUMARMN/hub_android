Copilot Skills for hub_android
=============================

This directory contains prompt-engineering "skills" tailored for Android development in this repository. Use these as templates to call from agents or directly paste into Copilot Studio / workflow integrations.

Included skills:
- `android-build` — build, reproduce and diagnose Gradle/CI issues
- `android-testing` — generate unit/instrumentation tests and test plans
- `kotlin-refactor` — refactor Kotlin idiomatically and safely
- `lint-style` — apply linting rules and generate `editorconfig`/ktlint fixes
- `dependency-updates` — check and suggest dependency upgrades with migration notes
- `docs-writer` — generate README sections, module docs, and usage examples
